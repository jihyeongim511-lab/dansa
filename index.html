      1-1. 개념 학습 모형

      개념의 종류

      • 상위·하위·동위 개념
      • 접합(결합) 개념: 밀접하게 관련된 여러 속성이 모여 하나의 개념 구성
      • 이접 개념: 서로 독립적인 속성 중 하나만으로 형성, 여러 대안
      • 관계 개념: 하나가 다른 것을 전제, 두 요소가 밀접한 상관·비교 관계

      ① 속성(고정) 모형 : 결정적 속성 중심 → 사례

      문제 제기→속성 제시와 정의→속성 검토→사례 검토(예/비례)→가설 검증→개념 분석·관련 문제 검토·평가
      장점
      교수·학습 단계가 논리적·인지적 활동 과정에 부합
      단점
      명확한 속성을 제시하기 어려운 추상적 개념에 약함
      • 사례 검토: 예에서 속성 분석, 비례에서 "속성이 아닌 점" 분석
      • 가설 검증: 새로운 대상을 제시하고 어떤 속성 때문에 예/비례인지 분석

      ② 원형 모형 : 개념의 원형(전형적 예)에서 결정적 속성 탐색

      문제 제기→원형과 정의 제시→비례 제시→속성 검토→개념 분석·평가
      장점
      속성이 모호해도 적절한 예로 이해도 상승
      단점
      여러 사례가 같은 개념으로 분류되는 기준을 분명히 제시하기 어려움

      ③ 상황 모형 : 사회·문화적 환경의 상황·경험·기대·행동 중심

      문제 제기→상황·경험 제시→사례 검토(예/비례)→속성 검토→개념 분석·평가
      장점
      역사적 맥락, 사회·문화적 상황에서 구체적으로 이해
      단점
      추상화·일반화에 제한, 배경지식 부족 시 활용 어려움, 다른 상황에 보편 적용 어려움

      1-2. 탐구 학습 모형

      지식·이론을 발견한 사고 과정과 방법을 재현합니다. 법칙성이 강해 일반화를 도출할 수 있는 주제에 적합합니다.

      일반화된 지식 = 사회과학적 지식 = 가치중립적 지식 = 객관적 지식. 인지 발달 수준에 따라 교사·학생의 역할 비중을 조절.

      문제 제기→가설 설정→자료 수집·분석→가설 검증·일반화

      마시알라스·콕스 (권오정, 김영석)

      탐구 문제 파악가설 설정탐색증거 제시일반화
      • 탐구 문제 파악: 탐구 상황 제시 → 학습 문제 설정
      • 가설: 원인-결과 관계 진술 (인과관계, 경향성)
      • 탐색: 가설 타당성 검토, 탐구 계획 수립 (자료 종류는 개념의 대표성·수집 가능성 기준)
      • 증거 제시: 자료 수집, 평가, 분석
      • 일반화: 결과 요약, 증거로 결론

      뱅크스, 울레버·스콧 (차경수, 모경환)

      문제 제기가설 설정용어 정의 및 개념화자료 수집자료 분석가설 검증 및 일반화
      • 문제 제기: 문제 상황을 예화로 제시
      • 가설: 제기된 문제에 대한 잠정적 결론
      • 용어 정의: 자료의 종류·수집 방법 고안에 유용
      • 일반화: 임시적 성격

      1-3. 문제해결 학습 모형

      문제 확인→문제 발생 원인 파악→해결 방안 탐색→해결 방안 결정→해결 방안 실천
      • 문제 확인: 시청각 자료, 개인에 미치는 심각성 → 해결 필요성 공감
      • 원인 파악: 정보의 신뢰성·타당성 점검, 정보 유목화, 원인-결과 연관성 사고, 사실과 가치 구분
      • 방안 결정: 장단점·비용편익 비교 분석, 순위 → 최적안 결정
      • 방안 실천: 실천 계획 세우기, 성과·부작용 논의
      장점
      일상 문제 해결에 유용한 지식, 문제해결 능력 신장
      단점
      문제와 관련된 일반적 원리·구조 파악 지도가 약함
      구분문제해결 학습탐구 학습
      문제
      일상적 문제
      과학적 문제 (객관적으로 조사·증명)
      자료
      일상적 자료와 정보
      과학적·객관적 자료

      1-4. 의사 결정 학습 모형

      사실과 가치가 혼재된 개인적·사회적 문제를 합리적으로 해결합니다.

      장점
      의사 결정력 발달, 행위의 실천
      단점
      합리적 결정이 항상 옳거나 공동체 전체의 이익은 아님

      뱅크스 모형

      문제 제기→사회 탐구→가치 탐구→의사 결정→행동
      • 문제 제기: 사실적·가치적 측면이 혼재함을 인식
      • 사회 탐구: 가설 설정 → 자료 수집 → 자료 분석 → 가설 검증 (의사 결정에 필요한 지식을 S가 스스로 획득)
      • 가치 탐구: 가치 문제·가치 갈등 확인 → 대안 검토와 결과 예측 → 가치 선택
      • 의사 결정: 사실 + 가치를 종합해 결과 예측
      • 행동: 가장 적절한 대안 선택, 선택에 따라 행동

      의사 결정 매트릭스 모형 (왜 선택되었는가?)

      문제 정의→대안 나열→선택 기준 작성→대안 평가(도표에 점수)→의사 결정(최고점 선택)

      1-5. 논쟁 문제 학습 모형 (윤리-법률, 법리 모형)

      논쟁 문제 = 사회적 문제: 찬반이 팽팽, 사회 다수에 영향, 정답이 없음.

      장점
      의사 결정력 (합리적으로 선택하고 그 선택을 옹호할 수 있는 능력)
      단점
      기본 가치만으로 명확히 해결하기 어렵고 보편적 기준·원리가 약함
      비판 입장내용
      진보
      사회에 대한 보수적 가치·규범 주입(기본 가치, 일반적 가치)
      보수
      사회적 쟁점을 제시해 사회 질서에 의문·혼란

      논쟁 문제의 유형 3가지

      유형의견 대립의 이유해결
      용어 정의 문제
      개념의 불명확
      개념의 명료화
      사실 문제
      사실 여부
      경험적 증거로 사실 증명
      가치 문제
      우선시하는 가치
      가치 갈등의 해결

      가치의 위계

      기본 가치>일반적(사회적) 가치>특수한(개인적) 가치
      • 기본 가치: 최상의 궁극적 가치 (예: 인간의 존엄성)
      • 일반적(사회적) 가치: 법에 의해 보장 (예: 재산권, 공정성)
      • 특수한(개인적) 가치: 특정 상황·집단에 적용

      올리버·셰이버 (하버드 모형) 단계

      단계내용
      문제 제기
      시청각 자료, 개인에 미치는 심각성 → 해결 필요성 공감
      개념의 명확화
      개념 정의가 불명확하면 토론이 어렵거나 의견이 대립될 수 있음을 인식
      사실의 경험적 확인
      경험적(객관적) 자료로 검증
      가치 갈등의 해결
      대립 가치를 비교해 우선순위 결정. 해결 기준은 법률적(윤리·법률적) = 기본적 = 궁극적 가치
      대안 모색 및 결론
      사실 확인, 가치 분석 결과를 종합해 대안 모색 → 대안의 긍·부정 결과를 비교·분석해 최적안 선택

      4단계: 문제 제기·가치문제 확인 / 분석 / 선택 및 결론. 분석을 풀어 쓰면 8단계입니다.
      분석: 개념의 명확화 → 사실의 경험적 확인 → 가치 갈등의 해결(대립 가치 분석) → 비슷한 다른 경우와의 비교 → 대안 모색과 결과의 예측

      논쟁 문제 학습에서 교사의 역할 유형

      켈리 모형 (4가지)

      • 배타적 중립형: 논쟁 문제 교수 자체를 반대
      • 배타적 편파형: 한쪽 입장만 학습, 다른 입장은 다루지 않음
      • 중립적 공정형: 다양한 시각 학습, 교사는 어떤 입장도 교육하지 않음
      • 신념을 가진 공정형: 다양한 시각 학습, 교사가 교육적으로 바람직한 방향 제시

      하우드 모형 (6가지)

      • 신념형: 교사가 자유롭게 자기 의견 내세움
      • 관심형: 자기 의견을 말하고, 다양한 의견을 객관적으로 소개
      • 옹호형: 다양한 시각 제시, 이를 종합해 교사 자신의 의견
      • 객관형: 다양한 시각을 모두 서술, 자기 의견은 말하지 않음
      • 공정한 의장형: 교사·학생이 다양한 시각을 토론, 교사 의견은 말하지 않음
      • 악마 옹호형: 교사 의견과 상관없이 학생 의견에 반대 입장만 (반대에 대응하며 입장이 견고해짐)

      1-6. 협동 학습 모형

      이질적 집단 구성, 개별적 책무성 부여, 적극적 상호 의존성 강화, 교사의 관리·감독 강화, 평가는 소집단 보상, 사회적 기능 발달 → 인지적·정의적 능력(협력, 의사소통, 토론)을 기릅니다.

      모형핵심 내용
      Jigsaw (원형)
      소집단 구성→전문가 학습지(하위 주제) 배부→전문가 집단 학습→소집단 학습→전체 학습지 작성·정답 확인→개별 평가·개별 보상
      단점: 하위 주제만 알아 전체 파악이 어렵고, 개별 보상이라 보상을 위한 상호 의존성이 약함
      Jigsaw Ⅱ

      TAI

      06각론 ③ 서양음악 이론

      주제내용
      음악 기호
      • 스타카토: 짧게 끊어서 연주
      • 테누토: 음의 길이를 충분히
      • 악센트: 그 음을 특히 세게
      • 페르마타(늘임표): 음의 길이를 2~3배로
      붙임줄 vs 이음줄
      붙임줄(타이): 같은 높이의 두 음을 붙여서 한 음같이 연주
      이음줄(슬러): 높이가 다른 음을 연결하여 끊어지지 않게 부드럽게 이어서 연주
      박, 박자
      박: 음악의 시간적 개념 중 기본이 되는 최소 단위 / 박자: 일정한 수의 박이 모인 것 + 셈여림
      박자 젓기
      4분의 2박자, 3박자, 4박자, 8분의 6박자 지휘 모형. 지휘 모형은 한 마디에 1번만 그림
      센내기와 여린내기
      센내기: 갖춘마디, 첫 박이 센박으로 시작 / 여린내기: 못갖춘마디, 여린박에서 시작 → 못갖춘마디는 시작과 끝나는 부분을 합하여 한 마디가 됨
      예비박: 음악의 첫 박이 시작되기 전 한 박자(준비)
      3/4 vs 6/8
      3/4박자: 3박자 계통, 한 마디가 둘로 나누어지지 않음 / 6/8박자: 2박자 계통, 한 마디가 둘로 나누어짐, 2/4박자로 지휘 가능
      셈여림표
      pp(매우 여리게 피아니시모) < p(여리게 피아노) < mp(조금 여리게 메조피아노) < mf(조금 세게 메조포르테) < f(세게 포르테) < ff(매우 세게 포르티시모). cresc.(크레셴도) 점점 세게, decresc.(데크레셴도) 점점 여리게
      빠르기말
      Andante(느리게) < Andantino(조금 느리게) < Moderato(보통 빠르기) < Allegretto(조금 빠르게) < Allegro(빠르게). 숫자 표시: ♩=120은 4분음표를 1분에 120회 연주하는 빠르기
      음이름 vs 계이름
      음이름: 고정된 이름(다, 라, 마…) / 계이름: 조성에 따라 바뀜(도, 레, 미…)
      이동도법 계이름: 도의 자리 바꾸어 읽기 / 고정도법 계이름: 다장조로 계이름 읽기, 악기 연주 시 편리
      조표 vs 임시표
      조표: 곡의 처음에 표시, 악곡의 조를 나타냄(으뜸음의 위치를 알려줌) / 임시표: 해당 마디에서만 적용, 옥타브 위나 아래 음은 적용 안 됨 (올림표, 내림표, 제자리표)

      제1 언어 습득 이론 (모국어 습득 이론)

      이론핵심 내용한계·특징
      Behaviorism
      (행동주의, Watson & Raynor)
      모든 학습은 습관 형성, 조건화의 결과. stimulus → response(mimicry·imitation) → reinforcement → correct habit formation / conditioning → repetition(drill), accuracy
      유기체 = tabula rasa, 외부 environment = 절대적. 창의·창조적 언어 습득을 설명하지 못함
      Nativism / Innatism
      (생득주의, Chomsky)
      언어 습득 장치 LAD(Language Acquisition Device). Input 자연스러운 언어 환경 → LAD 자연·무의식적 규칙 습득 및 내면화 → Output 규칙 조합, 무한한 발화
      specific innate ability → discover underlying rules
      Constructivism
      (구성주의, Piaget & Vygotsky)
      환경과 유기체 간 상호작용에 주목, 학습자의 능동적 역할. 학습 = cognitive dimension(내적 구성, 새로운 지식 재구성) / social dimension(타인과의 상호작용). Teacher-centered → Student-centered
      Functional Approach(기능적 접근): 언어의 기능 = 의사소통(목적)을 위한 수단. form(Generative linguistics) → functions(사회적 맥락, 화용론)

      제2 언어 습득 이론: Krashen의 Five Hypotheses

      가설핵심 내용
      ① Acquisition-Learning
      (습득-학습 가설)
      Acquisition: Natural communication, "Picking up", subconscious·implicit, form < meaning, fluency·intuition
      Learning: Formal teaching, "Knowing about", conscious·explicit, attend to form
      → non-interface position, mutually exclusive. ∴ do as much acquiring as possible in order to achieve communicative fluency
      ② The Monitor Hypothesis
      (모니터 가설)
      Learning → Output 전후 monitor, editor (polish). plenty of time, learned the relevant rules, is concerned about producing correct language 일 때 작동
      ③ The Input Hypothesis
      (입력 가설)
      Comprehensible input (i+1) (= intelligible). finely-tuned input(미세 조절 입력): X / roughly-tuned input(어림 조절 입력): O
      교사의 전략: modified input - 짧고 간단한 문장(syntactic modification), 자주 사용되는 어휘(lexical modification), Pedagogical Aids(realia, picture), 현재·지금에 대해 설명, 천천히 명확하게 발음
      Optimal Input = comprehensible, interesting·relevant, Grammatical Sequenced X, Sufficient Quantity
      Silent Period → 어느 정도 규칙 쌓이면 발화(강요 X), should not be forced to speak until they ready
      ④ The Affective Filter
      (정의적 여과막 가설)
      습득을 방해하는 심리적 장벽: motivation↓ confidence↓ anxiety↑ → Filter↑ → 습득 저해 (well-disposed to processing input)
      ⑤ The Natural Order
      (자연적 순서 가설)
      -ing, be V, -s 복수형 → be 진행형 조동사, 관사 a/the → 불규칙 과거형 → 규칙 과거형, 3인칭 단수 s, 소유격 's. 단순성에 의해 결정, independent of the class order. 문법 교육 필요 X → Zero Option(Position). Devopmentally ready: 발달적 준비

      그 밖의 가설

      가설핵심 내용
      Output Hypothesis
      (출력 가설, Swain)
      comprehensible input만큼 comprehensible output도 필요. Input = semantic process(어휘적), Output = syntactic process(어법적) → 서로 다른 처리 과정
      Output의 3가지 기능:
      1. Noticing Function: 목표어와 나의 출력 사이 오류 확인
      2. Hypothesis-testing Function: test various hypotheses ("try out")
      3. Metalinguistic Function: 문법에 대해 사고하는 기능
      (Pushed Output) 현재 구사력보다 약간 더 ↑ accuracy
      Interaction Hypothesis
      (상호작용 가설, Long)
      Interaction = 입출력을 정확하게 할 수 있는 기회. Modified Interaction → Meaning Negotiation(의사소통의 단절이 있을 때 pronunciation, vocabulary, morpho-syntactic, pragmatic 등으로 의미 협상)
      1. Comprehension Check 이해 점검 화자: "Do you know what I mean?"
      2. Confirmation Check 확인 점검 청자, 반복·되묻기: "Are you mean X?"
      3. Clarification Request 명료화 요구 청자: "Pardon?" "What do you mean?" (wh- / yes-no / tag question)
      Meaning Negotiation이 언어 습득에 미치는 영향:
      1. Input: Modified input (unmodified / premodified / interactionally modified)
      2. Output: corrective feedback → 수정된 발화
      Sociocultural Theory
      (사회문화적 가설, Vygotsky)
      근접 발달 영역 ZPD(Zone of Proximal Development): 학습자가 아직 혼자 기능하지 못하지만 도움(scaffolded help)으로 원하는 결과를 달성할 수 있는 지식·기술의 영역 (actual developmental level ~ potential developmental level)
      교수학습은 ZPD 내에서 이루어져야 한다 → Scaffolding: simplifying tasks, guiding learners in appropriate directions, marking critical features of language, structuring task for success. two-way street = social interaction = collaborate effort
      인지주의 이론
      • 지식의 2가지 종류: declarative
      • explicit knowledge(의식적, 초보 운전)
      • procedural
      • implicit knowledge(무의식적, 경력 10년). Automatization: declarative → procedural. 학습→습득 Interface: O(strong: Automatization, weak: Focus on Forms)
      • X(Krashen: non-interface position)

      전통적 교수법

      교수법핵심 내용
      GTM
      (문법-번역)
      일반원리 → 예시: deductive(연역적). accuracy↑, decontextualized(탈맥락화). 고립된 어휘와 문법 목록에 주의. 문자언어 Reading → exclusive focus. taught in the students' L1 / Translation exercises (L2 → L1)
      Direct Method
      (DM, 직접)
      GTM 반대. 문법 분석·번역 X, 문자언어 X. 음성언어 oral communication and listen skills → 듣기·말하기, 질문·대답. 모국어 사용 X, exclusively in the L2 → realia, picture, pantomime. 문법 inductive(귀납적)
      Audiolingual Method
      (ALM, 청화식)
      Drill - listen and repeat, pattern drill. accuracy↑, form > meaning
      언어 이론:
      1. Structural linguistic 구조주의 언어학(음소, 형태소, 단어, 문장을 구성하는 pattern)
      2. Contrastive analysis 대조 분석(L1 → L2 transfer(positive, negative), negative transfer = interference(간섭), 공통점/차이점 분석 → 간섭현상 예측)
      학습 이론: Behaviorism. 오류 → 즉각적 수정(부적 강화 X). extrinsic approval, praise, intrinsic self-satisfaction → reinforcement. mechanical habit formation: 이해 X
      목표: 듣기, 정확한 발음 → 원어민처럼 언어 사용, linguistic competence(grammatical competence)
      교수요목: contrastive analysis → structural syllabus(구조 중심 교수요목)
      활동: pattern → dialogue에 녹임, contextualizing Key structures, drill, memorization
      자료: tape recorder → accurate models
      절차:
      1. Key structures 포함한 model dialogue 들려줌

      Affective Factors 정의적 요인

      1. Motivation 동기

      동기↑ → 스스로 노출의 양과 사용의 기회를 늘리고자 함 (determines the direction, magnitude of behavior)

      종류내용
      instrumental motivation
      도구적 동기: 영어 → 어떤 목적 성취를 위한 도구. 직장 입사, 시험 utilitarian 실용적 (specific purpose that brings rewards)
      integrative motivation
      통합적 동기: 목표어 집단에 대한 긍정적 감정. 목표어 화자들이나 문화에 통합
      intrinsic motivation
      내재적 동기: 학습자 내부, 역량↑, 자아실현, 즐거움 (reward → the activity itself)
      extrinsic motivation
      외재적 동기: 학습자 외부, 학점, 돈, 칭찬, 처벌 X (reward from outside beyond the self)

      motivational strategies 동기 유발 전략: ① role model → 내재적 동기↑, 모범 보이기 ② autonomy 자율권 → 학습에 능동적으로 참여 ③ 칭찬, 격려 → self-confidence, 학습 결과물(portfolio) → 성취감 ④ 즐거움, 안정감, rapport 형성, 협동 장려 ⑤ 흥미로운 활동, 선호 차이 고려 → 다양한 종류의 활동, 여러 감각을 사용하게 하는 다양한 유형의 자료 ⑥ 실생활 관련, 실제 언어 사용 활동

      요인내용
      2. Inhibition 억제 심리
      자신의 자아를 보호하고자 하는 억제 심리 (build sets of defenses to protect the ego). 억제 심리↓ → 소집단 활동
      3. Anxiety 불안감
      debilitating(harmful) effect 부정적 효과↓: to flee the learning task to avoid the source of anxiety / facilitating(helpful) effect 긍정적 효과↑: to fight the new learning task, to make extra efforts to overcome their anxiety
      4. Risk-taking 모험심
      언어 습득에서 모험 → 시행착오를 통해 언어를 배우는 것. 어린이는 성인에 비해 모험심↑. Learners have to be able to gamble a bit, to be willing to try out hunches about the language and take the risk of being wrong

      1. MAP 과정: 교수·학습에 필요한 요소

      요소내용
      Motivation
      영어 학습에 흥미·관심 야기, 도전 의식 부여 → 적극 참여. 활동: 게임, 챈트, 노래, 그림, 스토리텔링
      Activation 및 Long-term memorization
      (Schema) Activation: schema 인간의 사전 경험, 사전 지식. pre-listening, pre-reading activities↑
      • 스키마의 유형: Content Schema(ta)(배경지식, sociocultural knowledge)
      • Formal Schema(ta)(how discourse is organized with respect to genres, topics, or purpose)
      • Long-term memorization(새롭게 입력된 정보 기능, 언어 형식을 장기 기억으로 부호화하는 과정)

      2. Fluency vs Accuracy

      학습 초기에 유창성 강조 → 점차 정확성 신장에 중점

      구분내용
      Fluency (의사소통 활동)
      언어 체계를 빠르게 작동하는 것. 머뭇거림 없이 말의 단위를 연결하는 능력, 의사소통 활동. disruptive pauses, restarts, breakdown X, being distracted X. "언어를 유창하게" → 정확성 전제 ∴ 균형!! 학습자가 자신이 하는 말의 의미를 알아야 함. 친숙함, 자신감 → 함정, 반복(기계적 X) internalization. message-oriented(= language use)
      Accuracy (통제 연습)
      언어 체계에 부합하는 것. 학생의 발화 오류에 대해 피드백 제공 통제연습. language-oriented(= language usage 용법)

      3. Skill Integration

      실제 의사소통 상황에서는 각 영역 뚜렷하게 구분 X → 두 가지 기능 이상을 통합적으로 사용하는 수업. Authentic language와 유사한 환경 제공. incremental language skill in tandem. Integrated-skill approach = interact naturally; a real means of interaction, sharing among people.

      4. CALL (Computer-Assisted Language Learning)

      풍부하고 다양한 형태의 input / 강한 학습 동기. T-S, S-S 실제적 상호작용 기회 제공. 개별화된 학습 내용, 자기 주도적 학습 환경.

      유형내용
      CMC
      Computer-Mediated Communication 매개. use target language for authentic and meaningful purpose. synchronous: messenger, zoom 실시간 / asynchronous: email, discussion forum
      Blended (= hybrid)
      온라인 + 오프라인(face-to-face, brick-and-mortar). control over the time and pace
      Flipped (= 거꾸로)
      traditional classroom instruction → viewed at home independently / collaborative, communicated, differentiated learning → class time

      05기능별 언어 지도 ② 듣기·읽기

      듣기 지도

      처리 방식내용
      bottom-up processing
      상향식 정보 처리
      듣기 자료 자체에 대해 정보 처리. 입력 자체를 음성·단어·구문·문장 순으로 decoding (linear fashion: smallest units → complete texts). meaning: derived as the last step in the process.
      1. 입력을 들으며 알고 있는 단어가 있는지 주목
      2. 음성의 흐름 → 구성요소로 나눔
      3. 정보의 초점 → 음운적으로 중요한 부분·단어에 주목
      4. 문법적 단서 사용
      • 유형: 음소 구별하기(bear / pear, laid / lead)
      • 문장의 억양 구별하기
      • 형태론적 어미 선택적으로 듣기(-ed)
      • 단어 식별하기
      top-down processing
      하향식 정보 처리
      activation of schemata, context 스키마, 맥락적 지식의 활성화. deriving meaning 의미 도출 global understanding 전체적 이해. interpretation of a text 텍스트 해석. contextual knowledge → specific listening situation, ongoing discourse.
      1. 상호작용: 특정 기능 및 목적에 할당
      2. 인과 관계, 말의 주제, 사건 간 연결, 빠진 부분 추론
      3. 결과 기대. 정서적 반응 파악하기 / 주제 파악하기
      interactive processing
      상호작용식
      상향식 + 하향식 듣기 전략을 모두 사용 → 정확한 이해, 전체적인 의미 파악. build a semantic network of word associations

      교실 듣기 유형

      유형내용
      responsive 반응
      교사 발화 즉시 이해, 적절히 즉각 반응. asking, command, seeking clarification, checking comprehension
      reactive 반사적
      단순히 따라 말하기 위해 들음. 의미 이해 X → 발음, 듣고 따라 말하기 연습. choral / individual drills(pronunciation)
      selective 선택적
      보다 긴 담화 → 특정 정보를 위해 선택적으로 듣기. 많은 정보 중에서 필요한 정보만 → 전반적 내용 X. 연설, 방송, 일화 등에서 이름, 날짜, 위치. listening cloze(blank), information transfer(listen → see)
      intensive 집중적
      특정 음소·단어·억양·담화 표지(discourse marker) 구별. bottom-up processing. she/he → phonemic, missed/miss → morphological, can(모음 약화)/can't(모음 약화 X) → stress
      extensive 확장적
      긴 강의, 대화, 이야기 → 전체적 의미, 목적. top-down processing. note taking, retelling
      interactive 상호작용적
      discussion, debate, conversation, role-play. pair and group work → 듣기 유형 모두(말하기 기능과 통합)
      selective vs intensive
      selective listening: 언어의 내용적 측면에 초점 / intensive listening: 언어의 형식적 측면에 초점

      과정 중심 듣기 지도 - 전·중·후

      단계내용
      Pre-Listening 듣기 전 활동
      • 듣기 자료와 관련한 내용적, 언어적 지식 활성화. essential background information, schema. 듣기 주제, 소재 이야기
      • 관련 어휘 및 표현 익히기(unknown vocabulary - central, which cannot be guessed form context)
      • 관련 그림을 보며 들을 내용 예측(select a suitable purpose, strategy)
      While-Listening 듣기 중 활동
      듣기 내용에 대해 이해. 들은 내용에 해당하는 그림 찾기, 도표/그림 완성하기 / 순서대로 그림 배열하기, 세부 정보 및 중심 내용 파악. help to process the meaning of the text. task that requires too much reading or writing X
      Post-Listening 듣기 후 활동
      들은 내용에 포함된 언어를 활용 및 확장. 다른 언어 기능 활동과 연계. 노래·챈트·게임·기도 / 들은 내용에 대해 말하거나 글쓰기. check students' understanding of a text. involve a microanalysis of sections of the text. recognize features that they were unable to process (blends, reduced words…). skill integration - make links to other skills. bottom-up - return to the text, examine some of its structure, grammar, vocabulary

      읽기 지도

      처리 방식내용
      bottom-up
      상향식
      음소와 문자의 대응 관계 인식 → 어휘, 문법, 의미, 담화 속 관계 파악. 문자를 상응하는 음성으로(철자-소리) decoding. recognize multiplicity of linguistic signals ← impose order
      top-down
      하향식
      기존에 가지고 있는 지식에 의존(inference) → 필자가 전하는 의미 이해. background knowledge, make(confirm / reject) prediction. all individual words are understood X. meaning-generating activity → mastery of bottom-up skill
      interactive
      상호작용식
      상향식의 정보 인식 방식 + 하향식의 오류 반복. 빠르고 효율적인 단어 인지 + 배경지식

      읽기의 단계

      단계내용
      1. Literal
      문자 그대로 이해. 명시적, 직접적으로 쓰인 그대로의 뜻
      2. 해석적 이해 (Interpretive / Inferential)
      문장에 쓰이지 않은 더 깊은 뜻 파악(정보 + 배경지식 이용). making generalizations 일반화하기. reasoning cause and effect 인과 관계 추론하기. anticipating endings 결말 예상하기
      3. 비판적 이해 (Critical)
      가치관, 수준, 사실의 정확성, 글의 질, 진실성 평가·판단. evaluate, pass personal judgment on the quality, values, accuracy, truthfulness
      4. 창의적 이해 (Creative)
      이해는 물론이고, 읽은 것에 토대 → 새로운 것 생각. applying information to new situations. 글에 대해 정의적으로 반응 responding emotionally

      읽기 전략

      전략내용
      Scanning
      미리 찾고자 하는 특정 정보를 염두에 두고 집중적으로 선택해 읽기 (사전, 전화번호부, 신문에서 필요한 광고, bus timetable). ex. "When did Mary die?" "Who ate the cake?"
      Skimming
      글의 전체적 윤곽, 중심 생각, 핵심적 요지 등을 파악하기 위해 세부 사항에 크게 구애 X 전체적으로 빠르게 읽기 (rapidly reading a text to get the gist, main ideas). ex. "What is the topic?" "Which title fits best?"
      Guessing / Inferencing
      • guess: the meaning of a word
      • grammatical relationship, discourse relationship
      • content message. infer: implied meaning, read between the lines 행간의 의미
      Semantic mapping 의미망
      (= a form of graphic organizer) 지문 속 여러 가지 사건, 생각을 관련된 것끼리 묶어 의미론적 지도 그리기. words, meanings, images, propositional content 사이의 관계 표현
      Thinking Aloud
      소리 내서 생각!: model how a good reader thinks about text while reading. student → learn to monitor their thinking

      과정 중심 읽기 지도 - 전·중·후

      단계내용
      Pre-reading 읽기 전
      • 읽기의 목적, 배경지식, 흥미 유발, 필요한 어휘 제시. 텍스트의 주제 단서를 보고 brainstorming
      • 텍스트의 그림, 사진, 표, 소제목 등만 보고 내용 예측
      • 읽을 내용과 관련된 어휘, 표현 익히기. reduce the difficulty level of the text → apply reading skills, strategies while reading
      While-reading 읽기 중
      • 읽은 내용에 대해 이해 → 의미 있는 과업 제시, 적극 참여 유도(ex. 의미망). reading aloud
      • silent reading
      • 구조 도식화 tree 완성, discourse marker 찾기
      • 읽은 내용에 해당하는 그림 찾기, 세부 정보 및 중심 내용 파악. narrative → number the sequence(non-sequentially)
      • information-based text → information-transfer task
      Post-reading 읽기 후
      • 글에 포함된 언어를 활용 및 확장, 다른 언어 기능 활동과 연계. 문법, 어휘, 구조 및 담화 특성 bottom-up
      • 노래, 챈트, 게임, 토론, 역할극
      • imagining, changing
      • 쓰기와 통합: 읽은 내용 그룹별 요약
      • 읽은 내용에 관하여 자신의 의견 말하기. review of the strategies
      • remembering↑

      유형내용

      말하기의 특성

      • information gap: 의사소통의 본질 = information 교환 → 화자와 청자 사이에 정보차(정보차 활동의 사용 권장). T(연필을 보여주며) What's this? S: It's a pen. 정보차 X
      • interaction 상호작용: 의미 협상, 명료화, 말의 순서 교대, 주제 선정, 말의 종결. 자신의 의사를 명확하게 표현하는 것은 물론 상대방의 의사도 이해·대처해야 함

      말하기 연습 활동 (Drill)

      유형내용
      Mechanical 기계적
      답 1개, 완전히 통제됨. 학습 초기 단계에서 학습자가 문장 의미 이해 X. memorize the pattern(mistake X)
      Meaningful 유의적
      2가지 이상 형태, 통제 조절. (학습자가 말할 내용 알고 있음, 정보차 X) 말하는 구문, 전체 의미 이해 O. less suitable for choral drilling 제창 연습에 적합 X
      Communicative 의사소통
      통제 X 구조 사용에 대해 어느 정도 통제된 말하기 연습. 자신이 말하고 싶은 것 선택하여 자유롭게 말함. add new information about real world. (학습자가 말할 내용 예측 불가능, 정보차 O)

      Interlanguage (= learner language) 중간언어

      a transitional point between L1 and L2 과도기. Independent system, not simply a degenerate form of L2.

      단계내용
      ① pre-systematic stage 체계 전 단계
      random errors, 체계적 질서 존재를 어렴풋이 인식
      ② emergent stage 출현 단계
      오류 지적 → 수정 X. backsliding 현상(seems to have grasped a rule, and then regresses to a previous stage) / U-shaped learning: 옳음 → 오류 → 다시 옳음 형태로 돌아옴
      ③ systematic stage 체계적 단계
      발화에 더 일관성, 오류 지적 → 수정 가능
      ④ stabilization / post-systematic stage 안정화 / 체계 후 단계
      유창, 스스로 수정 / △ Fossilization 화석화 (recurring errors permanent features of learner's speech)

      말하기 오류 지도

      분류내용
      Global error 포괄적/전체적
      의사 전달에 지장을 초래하는 정도에 따른 분류. impede communication, incomprehensible ("Look at the widow."). Fluency
      Local error 부분적/지엽적
      문법적으로 틀린 오류(accurate guess). Accuracy. 즉각적 오류 수정, 다양한 교정적 피드백 제공 ("I'm study English everyday.")
      Interference 간섭 오류
      = transfer error, interlingual error. 모국어의 간섭, 전이로 발음/어휘/구문/화용 오류
      Developmental 발달 오류
      = intralingual error. 목표어 자체의 규칙을 overgeneralization(과잉일반화) 하여 적용. 형태소/의문문/종속절 어순 오류
      • 오류의 원인: ① interlingual transfer 언어 간 전이 → interference error ② intralingual transfer 언어 내 전이 → developmental error ③ communication strategies 의사소통 전략
      • 오류의 수정: CLT - 전체 오류 O 지엽적 오류 X / PPP - 발화: 전체적 오류, 연습: 지엽적 오류

      Categories of Error Treatment 오류 처리 유형

      유형내용
      Explicit correction 명시적 교정
      Clear indication that form is incorrect. 교정된 형태 제공 (provision of a correct form). "No. You have to say -."
      Recast 고쳐 말하기
      의사소통 흐름 단절 X, 오류 수정해서 말해주는 암시적 피드백. reformulate, expand ill-form(unobtrusive way)
      Metalinguistic feedback 상위언어적
      올바른 언어 표현에 관한 질문·정보 제공(형태 제시 X). "What is the past tense form of go?"
      Repetition
      억양을 바꿔서 학습자 발화의 오류 반복
      Clarification Request
      이해 X, 잘못된 것이 있다는 것, 반복·재발화가 필요함을 알림. Pardon? Excuse me. What do you mean by -?
      Elicitation 유도해내기
      • 오류 직전에 전략적으로 멈춤 (I have three_?)
      • "How do we say ~ in English?"
      • 발화 답이 말할 것 요구

      input-providing
      recast
      explicit correction
      output-prompting
      repetition, clarification
      metalinguistic, elicitation

      쓰기 지도

      접근내용
      결과 중심 쓰기
      product-oriented, product approach
      단답적 쓰기, 결과물 중시, 정확한 낱말·구문 → 의미 표현. model(모범 글) 읽고 분석·모방 / 교사가 글 수정
      과정 중심 쓰기
      process-oriented, process approach
      pre-writing 초고 쓰기 → drafting → rewriting 고쳐 쓰기. recursive, cyclical 순환적 (improve writing at any, all stage). model 제시 지양, 자유롭고 창의적으로 생각·표현·수정하는 과정 중시. 의미·내용(초기) → 문법·철자 교정(편집). produce more than one draft for feedback, evaluation
      단계 (-writing)내용
      pre
      필요한 낱말·언어 형식 지도, 사전 경험 활성화, 동기유발, 샘플 제공. ① Planning 계획: 쓸 내용을 계획, 구상. 주제 선정, brainstorming, 정보 수집, outlining
      while
      ② Drafting 쓰기: 계획을 바탕으로 초안, 오류 X. first - messy. correctness gets in the way 방해가 됨
      post
      1. Revising 수정: 교사·동료의 피드백 검토 / 내용·표현 수정
      2. Editing 편집: mechanics(철자법, 대문자 등) 중심 점검·수정
      3. Publishing 출판: 전시, 발표
      Feedback
      Peer review: 동료 의사소통, 건설적인 피드백(실제 독자). Conference: T → give feedback, improvement. formative 형성적 > summative 총괄적. Error correction code(ECC)

      단계별 쓰기 활동 (controlled to free writing)

      단계내용
      ① Controlled writing 통제 작문 - 결과 중심
      완전한 통제, 선택권 X / 활동 졸업 - 교사의 의도, 오류 X, 쓰기에 자신감. copying, dictation, 제시된 문장 복사하여 알맞은 단어를 채워 넣기
      ② Guided writing 유도 작문 - 결과 중심
      • 어느 정도 선택권, 통제 O
      • 활동 결과 - 완전 일치 X
      • 언어 형태에 관심. 빈칸 채우기, 받아쓰기(반 불러줌), 편지·카드·초대장(형식 알려주고 쓰기). 예시 따라 쓰기(example 주고 새로 바꾸어 문장 만들기, 내용 생각, 어휘 제공)
      ③ Free writing 자유 작문 - 과정 중심(수정됨)
      • 교사 도움 X, 언어연습 X
      • 의사 표현·content에 초점
      • self-expression. 교정 지도: 쓰기 과정에서 학습자가 스스로 오류 인지, 스스로 고칠 수 있도록, 의미 전달에 문제가 있는 중대한 오류만 고치도록. 쇼핑 목록, 시간표, 일기, 만화 대사, 편지나 쪽지, 역할극 대본
      ④ Corrective feedback (= negative evidence) 교정적 피드백
      direct feedback: 교사가 고침, 바로 알아보지만 기억↓, 의미↓ → 목표 표현 제시, 정확성 연습 (자유롭게 쓰기). indirect feedback: 틀린 부분 표시 자신의 오류 파악/고칠 기회, 기억↑. cf. positive evidence: 무엇이 가능한지를 알려주는 정보

      구분내용
      분절 음소 (segmental phoneme)
      분절하여 인식할 수 있는 음, consonant 자음 + vowel 모음 → 철자 표기. 최소 대립쌍 맥락화 contextualized / meaningful minimal pair
      초분절 음소 (suprasegmental phoneme)
      분절 인식, 철자 표기 X
      stress 강세
      syllable prominence 두드러짐. 강세 X → [ə] (schwa)
      ① word stress: 2음절 이상 단어 → 한 음절에 강세. 강세 위치에 따라 품사(record), 뜻(object) 바뀌기도…
      ② sentence stress: 내용어(content word)에 강세, 기능어(function word)는 강세↓. 유동적 → 화자의 의도에 따라 달라짐
      rhythm 리듬
      1. syllable-timed language 음절 박자 언어: 문장 내의 음절 수에 따라 시간 다름, 한국어
      2. stress-timed language 강세 박자 언어: 등시간성이 → 강세 수에 따라 시간 다름, 영어
      intonation 억양
      melody of language - pattern of pitch change.
      1. falling intonation 하강조(고음 → 저음): 서술문, WH-의문문, 확인 부가 의문문, 선택 의문문

      Vocabulary 어휘

      1. 어휘 중심 접근법 (Lexical Approach)

      언어 습득과 의사소통 체계의 구축 단위는 단어의 결합이다. prefabricated chunk(multi-word combinations) 미리 조합된 말뭉치

      2. 어휘 분류

      분류내용
      passive vs active vocabulary
      수동적 어휘: 이해 O, 쉽고 빠른 표현 X / 능동적 어휘: 이해 O, 쉽고 빠른 표현 O. 능동적 어휘 지도 → 수동적 어휘를 능동적 어휘로 전환하도록 연습 기회
      content word vs function word
      내용어: 명·형·동·부사, 지시사, 의문사 - 독립적인 의미 / 기능어: 조동사·전치사·접속사·관사 - 문법적 기능
      chunk 말뭉치
      • 둘 이상의 낱말이 결합하여 고정된 meaningful unit = 여러 단어 묶은 단위. 의미 단위 전체를 통째로 익히기 (상황식 X) 자신의 실력↑ 의사소통. collocation 연어(함께 어울리는 단어들의 조합, 잘못 사용 → 문법 옳아도 어색한 표현)
      • phrasal verbs 구 동사(동사 + 부사(전치사), 그 구성요소와는 다른 의미를 갖는 동사. look after: 돌보다)
      • sentence frame 문장틀(would you mind if…? the thing is…)
      • discourse marker 담화 표지(before and what comes after, on the other hand, once upon a time)
      • idiom 관용구(두 개 이상의 단어가 특수한 의미)
      • saying 속담

      3. 어휘 선정 및 지도 방법

      • ① 어휘 선정: 학습자의 필요, 수준, 학습 목적에 따라 지도 어휘 선정. 어휘의 frequency, corpus(실제로 사용된 언어를 모아 만든 text) 사용 고려
      • ② word identification 어휘 식별 지도: 즉각적 식별 immediate identification = sight word / 분석적 식별 mediated identification = phonics 바탕으로 지도
      • ③ context를 활용한 어휘 지도 = inferencing: 의미 있는 context 내에서 습득될 수 있도록 학습자의 배경지식과 연계
      • ④ 3C (Convey, Check, Consolidate): 1) Convey meaning 의미 제시: 실물, 그림, 사진, 마임, 동의어, 일화 → 다양한 테크닉에 의존하여 의미 제시 2) Check understanding 이해점검: 1단계 단어와 관련된 일련의 질문 3) Consolidate 강화: 연습을 통해 강화, 능동적 어휘로서 사용. 의미 있는 맥락에서 사용할 기회 제공

      09평가

      평가 활동 = 수업 활동 + 평가 기준 + 피드백

      평가의 요건

      요건내용
      Practicality 실용도
      돈·시간↓, 실행·채점·해석이 쉬운 평가
      Reliability 신뢰도
      오차 X, consistent results. 요인: test, test taker 수험자, rater 채점자, the administration of a test 테스트의 실행. 채점자: intra-rater reliability: 1명의 채점자 / inter-rater reliability: 2명 이상의 채점자
      Validity 타당도
      평가의 목적 부합도, content validity. measure what it is supposed to measure
      Authenticity 진정성
      언어 평가 과업 - 실제 목표어 과업의 특징 간 일치 정도. natural, contextualized, interesting. Thematic organization to items. represent real-world task
      Washback effect 환류 효과
      • 평가 → 교수·학습에 미치는 영향 (교수·학습의 속도와 순서 / 내용 및 방법에 대한 태도). 평가 전에도 영향, 학습 중단·간섭 X. Informal 비공식적 평가 → interactive feedback. 긍정적 환류 효과 vs 부정적 환류 효과(수능). 점수만 제시 X, 평가 수행 구체적 설명
      • 약점에 대해 건설적 비평, 강점에 대해 칭찬
      • 특정 요소 어떻게 향상시킬 전략적 요령 제시

      평가의 목적에 따른 분류 (test)

      유형내용
      Proficiency 숙달도 평가
      전반적 언어 능력 측정 → 교육과정, 교과서 관계 X. global competence. 하나의 언어 기능에 국한 X
      Diagnostic 진단 평가
      학습자의 강점, 약점 파악. diagnose a particular aspect of a language
      Placement 배치 평가
      이미 가진 지식 측정 → 비슷한 수준끼리 같은 반에 배치. place a student into an appropriate level
      Achievement 성취도 평가
      상당한 기간에 걸친 과거의 학습을 되돌아보고 점검하는 summative 총괄 평가적 기능. limited to particular material covered in a curriculum within a particular time frame

      평가의 시기(function)에 따른 분류 (assessment)

      유형내용
      Summative 총괄평가
      학기말, 학년말 일정 기간의 수업이 끝났을 때. 교수의 결과로서 나타난 학생들의 학업 성취도를 측정. grasped at the end of a course. 결과중심
      formative 형성평가
      교수학습 과정 중, 수시로 평가, 교수학습 개선에 활용. evaluating students in the process of 'forming' their competencies. 과정중심
      결과 중심 평가 모형
      수업과 평가 단계 구분. 교육과정→(교수계획) 교수→(평가계획) 평가
      과정 중심 평가 모형
      수업과 평가 단계 구분 X, 평가는 수업의 일부. 학습 점검, 새로운 조치 취할지/계속 진도 나갈지 결정. 교육과정 → (교수 및 평가계획) 수업 ⟷ 평가
